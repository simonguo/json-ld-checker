# Security Policy

## Supported Versions

Security fixes are applied to the latest release and the current `main` branch.
Older extension packages may not receive patches.

## Reporting a Vulnerability

Please do not open a public GitHub issue.

Email [simonguo.2009@gmail.com](mailto:simonguo.2009@gmail.com) with:

- a description of the issue and its impact;
- affected versions or commit;
- reproduction steps or a proof of concept;
- any suggested mitigation;
- whether public disclosure has already occurred.

Do not include real API keys or private page content. You should receive an
acknowledgement within seven days. After validation, the maintainer will
coordinate a fix and disclosure timeline with the reporter.

## Security Scope

Relevant reports include credential exposure, unsafe script execution,
cross-origin data leaks, extension permission abuse, and vulnerabilities in the
AI provider or custom endpoint integration.
