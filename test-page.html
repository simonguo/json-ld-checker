🧪 JSON-LD Checker 测试页面

这个页面包含多个 JSON-LD 示例,用于测试插件功能

📋 使用说明

  1. 确保已安装 JSON-LD Checker 插件
  2. 查看浏览器工具栏,插件图标应该显示为 绿色
  3. 点击插件图标打开侧边栏
  4. 使用下拉菜单切换查看 3 个不同的 JSON-LD 数据
  5. 查看验证结果,了解每个 JSON-LD 的问题和建议

🔍 测试要点

  • 图标状态: 应该显示绿色,表示发现 JSON-LD
  • 数量检测: 应该显示 "发现 3 个 JSON-LD"
  • 树形视图: 可以展开/折叠查看数据结构
  • 原始数据: 显示格式化的 JSON
  • 验证结果: 显示错误、警告和建议
  • 切换功能: 可以在 3 个 JSON-LD 之间切换

💡 提示

  • 打开浏览器开发者工具 (F12) 可以查看控制台日志
  • 右键点击侧边栏选择"检查"可以调试侧边栏
  • 修改页面上的 JSON-LD 后刷新页面,插件会自动更新
  • 可以在 chrome://extensions/ 查看插件详情和错误

🐛 如果遇到问题

  1. 图标不变色: 刷新页面,确保插件已启用
  2. 侧边栏无法打开: 检查浏览器版本是否支持 Side Panel API (Chrome 114+)
  3. 显示"无法连接到页面": 刷新页面后重试
  4. 数据不更新: 点击侧边栏右上角的刷新按钮
