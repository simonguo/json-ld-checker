# 50-second demo video

Target length: 50–55 seconds. Record at 1920×1080 and export a captioned 16:9 MP4. Keep the pointer visible and avoid showing API keys.

| Time | Visual | Voice-over / caption |
| --- | --- | --- |
| 0–5s | Open a product page and invoke JSON-LD Checker. | “Inspect the JSON-LD on any page without leaving your workflow.” |
| 5–14s | Switch between Product, Offer, and BreadcrumbList entities. | “Every block, array, graph, and nested entity stays connected to its original source.” |
| 14–24s | Open a deliberately malformed block; zoom on line, column, excerpt, and caret. | “Broken JSON-LD is never mistaken for missing JSON-LD. See the exact line and column.” |
| 24–33s | Open Issues and click a finding to navigate to the matching JSONPath. | “Local Schema.org checks take you directly to the relevant node.” |
| 33–40s | Open Google Rich Results Test, then Schema.org Markup Validator. | “Confirm platform eligibility with official validators in one click.” |
| 40–48s | Open the focused report and click Download HTML / Print or save PDF. | “Export raw blocks, errors, and findings as an HTML or PDF-ready report.” |
| 48–55s | End card with logo, privacy line, GitHub, and Chrome Web Store button. | “Open source. Local first. Install JSON-LD Checker.” |
