# JSON-LD Checker press kit

## Short description

JSON-LD Checker is an open-source Chrome extension that preserves every JSON-LD
source block, pinpoints malformed JSON by line and column, inspects arrays,
`@graph`, and nested typed entities, opens official validators, and exports
focused HTML/PDF-ready reports.

## One-paragraph description

JSON-LD Checker helps developers and technical SEO teams diagnose structured
data without losing the original source. Unlike scanners that retain only
successfully parsed objects, it keeps invalid JSON-LD visible with exact syntax
locations. Local Schema.org checks are labeled separately from Google
rich-result eligibility, and one-click shortcuts open both Google Rich Results
Test and Schema.org Markup Validator. Core inspection runs locally with minimal
permissions; automatic all-site detection and AI tools are optional.

## Key facts

- Category: developer tools / structured data / technical SEO
- Price: free
- License: MIT
- Platforms: Chrome and compatible Chromium browsers
- Languages at launch: English and Simplified Chinese
- Data model: multiple blocks, top-level arrays, `@graph`, nested typed entities
- Default access: active page only after user invocation
- Optional access: all-sites automatic detection, requested only when enabled
- Telemetry: none inside the extension
- AI: optional, bring your own provider and key
