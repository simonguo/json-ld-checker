# AI 功能使用指南

## 概述

JSON-LD Checker 现在集成了强大的 AI 功能，可以帮助您：
- 深度分析现有的 JSON-LD 数据质量
- 智能生成适合您网站的 JSON-LD 代码
- 提供专业的 SEO 优化建议

## 功能特性

### 1. AI 检查 🤖

**功能说明**：使用 GPT-4 模型深度分析当前页面的 JSON-LD 数据

**适用场景**：
- 已有 JSON-LD 数据，想检查是否存在问题
- 需要专业的 SEO 优化建议
- 想了解 JSON-LD 是否符合 Schema.org 规范

**检查内容**：
- ✅ 语法错误检查
- ✅ Schema.org 规范验证
- ✅ 必需字段完整性检查
- ✅ 数据类型正确性验证
- ✅ SEO 最佳实践建议
- ✅ 优化改进方案

**使用方法**：
1. 打开包含 JSON-LD 的网页
2. 点击插件图标打开侧边栏
3. 切换到 "AI 检查" 标签
4. 等待 AI 分析完成（约 3-10 秒）
5. 查看详细的分析报告
6. 点击 "重新检查" 可重新分析

### 2. AI 建议 💡

**功能说明**：根据页面内容智能生成合适的 JSON-LD 结构化数据

**适用场景**：
- 网站还没有 JSON-LD 数据
- 想为页面添加新的结构化数据类型
- 需要补充或改进现有的 JSON-LD
- 不确定应该使用哪种 Schema.org 类型

**生成内容**：
- 🎯 页面类型自动识别
- 📋 推荐的 Schema.org 类型
- 💻 完整可用的 JSON-LD 代码
- 📝 实施说明和建议
- 🔄 对现有数据的改进方案

**使用方法**：
1. 打开任何网页（有无 JSON-LD 均可）
2. 点击插件图标打开侧边栏
3. 切换到 "AI 建议" 标签
4. 等待 AI 生成建议（约 5-15 秒）
5. 查看生成的 JSON-LD 代码
6. 点击 "复制代码块" 按钮复制代码
7. 将代码添加到您的网页中

## 配置指南

### 获取 OpenAI API Key

1. 访问 [OpenAI Platform](https://platform.openai.com/)
2. 注册或登录账号
3. 进入 [API Keys](https://platform.openai.com/api-keys) 页面
4. 点击 "Create new secret key"
5. 复制生成的 API Key（格式：sk-...）

### 配置 API Key

1. 点击插件侧边栏顶部的设置按钮 ⚙️
2. 在 "OpenAI API Key" 输入框中粘贴您的 API Key
3. 点击 "测试连接" 验证配置是否正确
4. 点击 "保存配置" 保存设置

### 管理 API Key

- **查看状态**：设置页面会显示 API 配置状态
- **测试连接**：验证 API Key 是否有效
- **清除配置**：删除已保存的 API Key
- **重新配置**：随时可以更新 API Key

## 使用技巧

### AI 检查最佳实践

1. **选择正确的 JSON-LD**：如果页面有多个 JSON-LD，使用下拉菜单选择要检查的数据
2. **理解建议优先级**：AI 会区分必须修复的错误和可选的优化建议
3. **结合验证结果**：AI 检查可以补充基础验证功能，提供更深入的见解
4. **多次检查**：修改后可以重新检查，验证改进效果

### AI 建议最佳实践

1. **提供完整信息**：确保页面标题、描述等元信息完整，AI 会生成更准确的建议
2. **检查生成代码**：复制代码前，先检查是否符合您的需求
3. **适当修改**：根据实际情况调整生成的代码
4. **测试验证**：添加到网页后，使用基础验证功能检查是否正确

### 节省 API 费用

1. **按需使用**：只在需要时使用 AI 功能
2. **缓存结果**：复制并保存 AI 生成的结果，避免重复调用
3. **批量处理**：对于相似页面，可以复用 AI 建议
4. **使用基础验证**：简单问题可以使用免费的基础验证功能

## 技术细节

### 使用的模型
- **模型**：GPT-4o-mini
- **温度**：0.3（检查）/ 0.5（建议）
- **最大 Token**：2000
- **响应格式**：Markdown

### 数据隐私

**发送到 OpenAI 的数据**：
- JSON-LD 数据内容
- 页面 URL
- 页面标题
- 页面描述（如果有）

**不会发送的数据**：
- 页面完整 HTML
- 用户个人信息
- Cookie 或认证信息
- 其他敏感数据

**API Key 存储**：
- 使用 Chrome Storage Sync API
- 仅存储在浏览器本地
- 可以跨设备同步（如果启用 Chrome 同步）
- 不会发送到任何第三方服务器

### API 调用流程

```
用户操作 → 插件收集数据 → 调用 OpenAI API → 接收响应 → 格式化显示
```

### 错误处理

插件会处理以下错误情况：
- ❌ API Key 未配置
- ❌ API Key 无效
- ❌ 网络连接失败
- ❌ API 调用频率超限
- ❌ 其他 API 错误

## 常见问题

### Q: 需要多少费用？
A: 使用 GPT-4o-mini 模型，每次调用约消耗 500-1500 tokens，费用约 $0.001-0.003。具体费用请查看 [OpenAI 定价](https://openai.com/pricing)。

### Q: 可以使用其他 AI 模型吗？
A: 当前版本仅支持 OpenAI API。如需支持其他模型，请提交 Issue。

### Q: AI 生成的代码可以直接使用吗？
A: AI 生成的代码是基于最佳实践的建议，但建议您：
1. 检查代码是否符合实际情况
2. 根据需要调整内容
3. 使用验证功能检查
4. 在测试环境中验证

### Q: 为什么 AI 检查结果与基础验证不同？
A: 
- **基础验证**：基于规则的快速检查，检查必需字段和常见问题
- **AI 检查**：使用 AI 模型深度分析，提供更全面的建议和优化方案

两者互补，建议结合使用。

### Q: 可以离线使用 AI 功能吗？
A: 不可以。AI 功能需要调用 OpenAI API，必须联网使用。

### Q: API Key 会过期吗？
A: OpenAI API Key 不会自动过期，但您可以在 OpenAI 平台手动撤销。如果 API Key 被撤销，需要重新配置。
